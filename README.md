## 📖 Overview

The **Admin Portal** is a modern Next.js 16 Web application for studio owners and platform administrators to manage studio accounts, issue license keys, monitor activated devices, manage subscription tiers (Starter, Professional, Studio, Lifetime), and send realtime alerts.

<br/>

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 App Router](https://nextjs.org/)
- **UI & Design System**: Tailwind CSS v4, Shadcn UI / Radix primitives, Lucide Icons
- **Data Fetching & Caching**: TanStack Query v5 + Axios
- **Data Tables**: TanStack Table v8
- **Notifications**: Sonner Toasts

<br/>

## 🚀 Quick Start

### 1. Environment Setup

Create a `.env.local` file in `photo-picker-pro-admin`:

```env
NEXT_PUBLIC_API_URL="http://localhost:3001"
```

### 2. Install & Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
